# Python reference implementation sanity check

시작 현금 100,000.00 G, 부채·상환·이자 없음. 순자산 = 현금 + 현재 재고 감정가.
운영비 = 2,000 × week; 기간 합계 156,000.00 G.
재고 10 → 20칸, 슬롯당 확장비 10,000.00 G.
확장·고물상 처분은 게임에서 플레이어 선택이다. baseline은 자동 매입·판매·확장 heuristic을 사용하고 자동 scrap은 하지 않는다.
음수 현금 허용은 simulation-only 정책이며 실제 게임의 현금 부족 처리는 플레이 테스트 후 결정한다.
